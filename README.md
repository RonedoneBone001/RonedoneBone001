I created Takcas Prime. It's a multi-agent IT factory that runs locally on an 8GB Android tablet. It writes, reviews, and tests Python code using Ollama and a custom memory management architecture.

## What I've Built
- Multi-Agent Pipeline: Coder -> Analyzer -> Critics -> Judge -> Sandbox.
- Memory Optimization: Switched from CLI to Ollama HTTP API with `num_ctx: 2048` to prevent OOM crashes on Android.
- Smart Sandbox: Blocks dangerous commands and runs generated code in isolation.
- Result: The factory successfully generated and launched a working Flask web app on `127.0.0.1:5000`.
